# Subject-Independent Recognition of Gym Exercises from Wearable Sensors

Hemanth Kumar Reddyvari (a3185100), Programming for AI and ML 2, final project.

How does testing on people a model has already seen distort the apparent benefit of deep learning for wearable exercise recognition, and can the distortion be reduced? This repository holds the code and the saved results behind the final report.

| Folder | Contents |
|---|---|
| [`2 Code/`](2%20Code/) | The notebooks, the workout logger app (`App.zip`) and a README on how to run everything |
| [`3 Results/`](3%20Results/) | Saved results used in the report: `results_final/` (main notebook), `results_ext/` (extension notebook, including the app), `figures_final/` |

Data: RecGym on Kaggle, `zhaxidelebsz/10-gym-exercises-with-615-abstracted-features` (not included; the notebooks download it). All training ran on Google Colab with a T4 GPU.
